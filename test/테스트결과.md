# 9번 먼저 할 일 : 테스트 결과 (2026-11-16)

## 1. CODAP 임베드 + CSV 불러오기 (A 방식)
- `?url=CSV주소` 동작 확인 (v2, 공개 https CSV 사용 시 표가 바로 열림)
- localhost CSV는 실패 : 공개 사이트(CODAP)가 내 컴퓨터 주소를 못 읽게 브라우저가 막음. GitHub Pages에 올리면 해결되지만 배포 전에는 테스트 불가
- 단점 : 속성 종류(숫자 / 범주) 지정 불가, 데이터 이름이 파일명으로 들어감

## 2. 플러그인으로 그래프 그림 가져오기
- 플러그인(`?di=`)도 localhost에서는 같은 이유로 로드 실패
- 대신 **`embeddedServer=yes`** 시험 : 사이트(부모 페이지)가 iframe-phone으로 CODAP API를 직접 호출. 플러그인 불필요
- 결과 (v2, v3 둘 다 성공)

| 기능 | API | v2 | v3 |
|---|---|---|---|
| 데이터 만들기 (한글 속성명, 숫자 / 범주 지정) | `create dataContext`, `create item` | O | O |
| 표 열기 | `create component (caseTable)` | O | O |
| 그래프 만들기 | `create component (graph)` | O | O |
| X축, Y축 속성, plotType 읽기 | `get component[이름]` | O | O |
| 그래프 그림 PNG | `get dataDisplay[이름]` → `exportDataUri` | O (약 170KB) | O |

- CODAP 화면 언어 : v2, v3 모두 영어 (`lang=ko` 미지원). 한글 속성명은 정상 표시
- embeddedMode에서는 상단 도구 막대가 숨겨짐 → 그래프 만들기 버튼을 사이트 오른쪽 패널에 둬야 함

## 지도 (화면 제작 중 추가 확인)
- CODAP v3 지도는 속성 이름에 `lat`, `long`이 있어야 위치로 인식 → `위도`, `경도`를 `위도(lat)`, `경도(long)`로 바꿔 넣음
- 지도는 `get dataDisplay`가 "DataDisplay not found" → 그림 내보내기 불가
- 대안 : 사이트가 같은 데이터로 지도 그림을 직접 그림 (Esri 회색 배경 지도 + 점, 학생이 고른 속성으로 색칠)

## 3. 결정한 구조
- CODAP v3 (`codap3.concord.org`) + `embeddedMode=yes&embeddedServer=yes`
- 데이터 : 사이트와 같은 저장소의 `data/*.csv`를 사이트가 읽어 API로 넣음 (CORS 문제 없음)
- 그래프 가져오기 : 사이트가 `componentList`에서 그래프를 찾아 PNG + X/Y 속성 + plotType 저장
- 그래프 종류 : 학생이 직접 선택 (plotType은 참고용으로 함께 저장. 산점도만 확인했고, 상자그림 같은 추가 요소는 plotType으로 구분되는지 미검증)
- PNG는 용량이 커서 구글 시트 셀(5만 자 제한)에 바로 못 넣음 → Apps Script에서 구글 드라이브 파일로 저장하고 시트에는 파일 ID만 기록
