데이터 분석 수행평가 (수행평가 테스트)

학번, 이름, 비밀번호 입력

이 사이트 전용 숫자 4자리 (다른 곳에 쓰는 비밀번호 사용 금지)
처음 접속, 지금 입력한 번호가 비밀번호로 설정됨

평가 규칙 확인

모두 읽은 뒤 시작

  • 1
    데이터 6개 중 골라 시각화 3개 만들기 (같은 데이터 여러 번 사용 가능)
  • 2
    그래프 종류 3개 모두 달라야 함, 같은 종류가 있으면 감점
  • 3
    시각화마다 질문, 관찰, 근거, 결론 작성
  • 4
    해석은 직접 입력만 가능 (복사, 붙여넣기 불가)
  • 5
    평가 중 전체 화면 유지. 다른 탭, 다른 창 이동, 화면 분할, 캡처 시도는 모두 선생님께 기록됨
  • 6
    3개를 다 못 해도 작성한 만큼 제출 가능. 제출 후에는 선생님께 수정 요청, 승인되면 다시 작성 가능

그래프 종류 알아보기

무엇을 알고 싶은지에 따라 알맞은 그래프가 다름. 3개 모두 다른 종류로 만들기

작업 화면에서도 "그래프 종류 설명"으로 다시 보기 가능
